# 产品功能交接包（V1 下线后的单一学习流）

> 更新日期：2026-09-30
> 适用状态：V1 节点学习流已下线；课程生成、学习、持久化只走 V2 协议。  
> 这份文档写给后续开发者/AI Agent：先看功能契约，再看代码。不要从旧 V1 设计文档推断当前行为。

## 1. 产品一句话

用户输入学习诉求，系统生成中文课程目录，按章节流式学习，支持提问、检测、补救和课程总结；课程数据可本地保存，也可切换为服务端保存。

## 2. 用户可见流程

### 2.1 登录
- 入口：`/login`
- 身份：邀请码，cookie 鉴权。
- 受保护路由：`/`、`/course/*`、`/generate/*`、`/profile/*`、`/review/*`。
- 预期：无效或过期邀请码被重定向登录页。

### 2.2 首页 `/`
- 空状态展示两门系统推荐课程。
- 点击系统课：
  1. 用内置大纲元数据派生 `CourseBlueprintV2`；
  2. 保存 V2 课程容器；
  3. 跳转 `/course/{courseId}`。
- 有课程时展示“最近学习”：主题、下一章、完成度、继续学习、删除。
- 已无 V1 兼容；旧 V1 课程不会出现在列表中。

### 2.3 新建课程 `/generate/chat` → `/generate/toc`
1. 用户描述目标、基础、方向。
2. `/api/agents/outline` 与 Python Agent 对话生成课程纲要。
3. `/api/generate/toc` 获取目录 SSE 流。
4. Outline 派生 `CourseMission` 并随 TOC prompt 注入；前端把 TOC 映射为 `CourseBlueprintV2`。
5. 校验通过并保存成功后跳转课程页。
6. 校验失败、空目录或保存失败：显示错误和重试，不再降级 V1。

### 2.4 课程页 `/course/{courseId}`
- 展示课程目标、章节树、完成度、当前可学章节。
- `available` 章节可点击；`locked` 章节不可点击。
- 全部章节完成后展示庆祝弹窗。
- 右下角课程问答仍可用。

### 2.5 章节学习 `/course/{courseId}/chapter/{chapterId}`
- 章节计划按需生成。
- 学习任务以 SSE 流式输出，支持任务边界、流内提问、检查点、补救。
- 章节完成后刷新课程树并解锁下一章。
- 章节总结按需生成。

## 4. 数据契约

### 4.1 `CourseBlueprintV2`
- 必须有：`protocolVersion: 2`、topic、学习意图、起点、课程目标、章节。
- 新课程携带 `CourseMission`：why、targetScenario、successCriteria、constraints、outOfScope。
- 章节必须：ID 唯一、index 唯一、目标存在、前置依赖存在且无环。
- TOC 映射层：`lib/learning-v2/blueprint-map.ts`。
- 校验入口：`validateCourseBlueprintV2`。

### 4.2 `StoredCourseV2`
- 包含 `courseId`、blueprint、treeView、createdAt。
- 可选沉淀 `references`（章节速查卡）和 `glossary`（统一术语）。
- 课程列表只从 `StoredDataV2.v2Courses` 派生，不再消费 `courses`（V1）。
- 删除课程必须同时清理：课程容器、各章 lesson key、服务端数据。

### 4.3 `NodeLessonV2`
- 每章独立存储；最后一个任务触发 Checkpoint，评估结果进入 `evidence`。
- local key：`ai-learning-data-v2[:inviteCode]:course:{courseId}:chapter:{chapterId}`。
- server 模式经 `/api/user/lessons` 读写，保存可用 `expectUpdatedAt` 做乐观锁。

### 4.4 存储模式
- `NEXT_PUBLIC_LESSON_STORE=local`（默认）：localStorage。
- `NEXT_PUBLIC_LESSON_STORE=server`：服务端优先，本地缓存仅兜底。
- server 模式读取课程时按章节真实状态自愈 treeView。

## 5. 服务端 API 契约

### Next 代理
- `GET /api/user/courses`：读账户课程。
- `POST /api/user/courses`：覆盖保存账户课程列表。
- `DELETE /api/user/courses?courseId=...`：删除课程。
- `GET /api/user/lessons?courseId&chapterId`：读章节。
- `PUT /api/user/lessons`：保存章节，409 表示版本冲突。
- `POST /api/user/engagement`：追加参与信号。

### Python Agent
- 所有 `/api/*` 请求要求内部令牌；用户身份由 Next 代理注入 `X-Account-Id`。
- `DELETE /api/user/courses`：删除课程主对象、所有章节 lesson 文件和该课 engagement 文件。
- 服务端存储目录：`python-agent/data/user_data/{accountId}/`。

## 6. 关键不变量

1. 不允许新课程写入 V1 `courses` 容器。
2. 不允许 V2 校验失败后降级成半可用课程。
3. 章节解锁必须由章节真实完成状态派生，不能只信课程树缓存。
4. server 模式课程创建：服务端保存成功后才写本地镜像；保存失败必须提示失败。
5. 删除课程必须走 `LessonRepository.deleteCourse`，不能只删 UI 列表。
6. 用户可见文本使用中文；API 错误需要可重试信息。
7. 每章最后一个任务必须触发理解检查；只有评估结果可写入用户 Memory 投影。
