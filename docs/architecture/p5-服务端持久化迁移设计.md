# P5 服务端持久化迁移设计

> 状态：设计稿（存储后端选型待定，接口契约与抽象层设计与后端无关）
> 日期：2026-09-20
> 前置：P0–P4 已交付（本地 localStorage 单设备运行时）
> 对应规格：v2_项目综述.md §P5 / v2_课程生成逻辑.md §P5

## 1. 目标与非目标

### 目标
- 课程运行时（StoredCourseV2 / NodeLessonV2 / 参与信号）从 localStorage 迁移到服务端。
- 多设备恢复：任一设备可继续任意课程。
- 账户级数据隔离（inviteCode 即身份，沿用现有鉴权）。

### 非目标
- 不改 V1 课程行为（V1 保持现状直至旧协议迁移完成）。
- 不做实时协同/多端同时写（先保证单设备会话一致性，见 §5 冲突策略）。
- 不引入新鉴权体系（沿用 inviteCode cookie）。

## 2. 存储抽象层（后端无关的第一步）

`lib/learning-v2/storage.ts` 现有函数收敛为 `LessonRepository` 接口：

```ts
interface LessonRepository {
  loadCourse(courseId: string): Promise<StoredCourseV2 | null>;
  saveCourse(course: StoredCourseV2): Promise<void>;
  loadLesson(courseId: string, chapterId: string): Promise<NodeLessonV2 | null>;
  saveLesson(courseId: string, chapterId: string, lesson: NodeLessonV2): Promise<void>;
  listCourseSummaries(): Promise<StoredCourseV2[]>;
  appendEngagement(courseId: string, events: EngagementEvent[]): Promise<void>;
}
```

- `LocalLessonRepository`：现有 localStorage 实现的薄包装（保持现有行为，SSR 安全）。
- `ServerLessonRepository`：P5.1 实装（HTTP 调用 §3 API）。
- 切换由环境变量 `NEXT_PUBLIC_LESSON_STORE=server|local` 控制，默认 local（零行为变化）。
- 迁移期双读：server miss 时回退 local 并回传（§6 数据迁移）。

## 3. API 契约（与存储后端无关）

所有端点走现有 `requireAuth`（inviteCode cookie 即账户身份）。

| 方法 | 路径 | 语义 |
|---|---|---|
| GET | `/api/user/courses` | 账户下全部课程摘要（StoredCourseV2[]） |
| POST | `/api/user/courses` | 创建/整体保存课程主对象（蓝图 + treeView） |
| GET | `/api/user/lessons/:courseId/:chapterId` | 读取单章学习容器 |
| PUT | `/api/user/lessons/:courseId/:chapterId` | 保存单章学习容器（携带 updatedAt 乐观锁） |
| POST | `/api/user/engagement/:courseId` | 批量追加参与信号（fire-and-forget） |

约定：
- 错误体沿用 `{ok, code, message, retryable}`。
- 409 = updatedAt 冲突（返回服务端当前版本，客户端决策 §5）。
- 413 = 单章负载超限（触发既有归档压缩路径后重试）。

## 4. 数据模型（概念层）

三张逻辑实体（具体建表由后端选型决定）：

1. **courses**：id（courseId）、账户、蓝图 JSON、treeView JSON、createdAt/updatedAt。
2. **lessons**：courseId + chapterId 复合键、NodeLessonV2 JSON、updatedAt（乐观锁）。
3. **engagement_events**：courseId、eventType、chapterId/taskId、at；按月分区可清理。

单章负载治理沿用 §6.1.1 归档压缩（服务端 413 兜底与本地配额同路径）。

## 5. 同步与冲突策略

- **客户端为主写入**：hook 持有的 lesson 是事实来源，saveLesson 全量覆盖（与现有 localStorage 语义一致）。
- **乐观锁**：PUT 携带客户端 updatedAt；服务端 newer 则 409。
- **409 处理（第一版）**：提示「在其他设备上有更新」，提供「用本地版本覆盖 / 加载服务端版本」二选一；不做字段级合并（V2 数据以学习流条目 sequence 幂等，未来可做条目级合并）。
- **会话内节流**：沿用 300ms 节流 + 终态立即写；Page hide 时 flush。
- **离线降级**：网络失败回退本地队列，恢复后重放（fire-and-forget，静默）。

## 6. 数据迁移路径

1. 首次 server 登录：扫 localStorage 全部 V2 课程 → 批量 POST（本地键不清除，双写一个版本周期）。
2. 双写期：`NEXT_PUBLIC_LESSON_STORE=local` 保留默认，用户自愿开启 server。
3. 收敛：server 稳定后默认 server + local 只读回退；最终移除双写。
