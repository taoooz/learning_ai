## 🎯 实现策略

### 方案 1：懒加载（推荐）⭐⭐⭐⭐⭐

```typescript
// 只在需要时构建图谱
let cachedGraph: ConceptGraph | null = null;

function getConceptGraph(blueprints: CourseBlueprint[]): ConceptGraph {
  if (!cachedGraph) {
    cachedGraph = buildConceptGraph(blueprints);  // 0.01ms
  }
  return cachedGraph;
}

// 在 Memory Agent 中使用
export function getTeachingMemoryPayload(input: {
  nodeConcepts: string[];
  blueprints: CourseBlueprint[];  // 传入所有 blueprint
  ...
}) {
  const graph = getConceptGraph(input.blueprints);  // 懒加载
  const prerequisites = getPrerequisites(input.nodeConcepts, graph);
  ...
}
```

**优势**：
- ✅ 首次构建 < 1ms
- ✅ 后续使用缓存（0ms）
- ✅ 对 blueprint 生成无影响

### 方案 2：预构建（备选）⭐⭐⭐

```typescript
// 在 blueprint 生成后立即构建
async function generateToc(topic: string) {
  const blueprint = await callPythonAgent(topic);
  
  // 立即构建图谱并缓存
  const graph = buildConceptGraph([blueprint]);  // 0.01ms
  saveConceptGraph(blueprint.courseId, graph);
  
  return blueprint;
}
```

**优势**：
- ✅ 分散构建成本
- ✅ 图谱持久化存储

**劣势**：
- ⚠️ 需要额外存储空间（~10KB/课程）
