# AI 助理上下文逻辑设计

## 目标

优化 AI 助理的上下文管理，解决以下问题：
1. 上下文隔离层级混乱（history 按课程隔离，memory 全局共享）
2. 无过期机制，数据只增不减
3. 消息截断简单粗暴，可能破坏问答完整性
4. 缺乏上下文内容的精简策略

---

## 设计决策

### 1. 上下文隔离层级

**决策：课程级别**

| 数据类型 | 隔离方式 | 说明 |
|----------|----------|------|
| ChatHistory（对话历史） | 按 `courseId` 隔离 | 每个课程有独立的对话历史 |
| UserMemory（用户记忆） | 全局共享 | 跨课程利用知识薄弱点和兴趣 |

**理由**：
- 用户在一个课程内的提问通常是连贯的
- 跨课程（如同时学习"Python基础"和"数据结构"）时，对话不应混淆
- userMemory 全局共享可让 AI 了解用户的整体知识状态

---

### 2. 过期机制（混合策略）

| 数据类型 | 过期策略 | 说明 |
|----------|----------|------|
| ChatHistory（对话历史） | **7天过期** | 未访问则不传给 AI，但保留在存储中 |
| KnowledgeGap（知识薄弱点） | **长期留存** | 无过期，但可标记"已掌握"降级 |
| QuestionPattern（问题模式） | **保留最近50条** | 超出则删除最旧的 |
| Interests（兴趣） | **权重衰减** | 30天无交互则降低权重 |

**对话历史过期流程**：
1. 对话历史超过7天未访问
2. 调用 AI 生成一句摘要
3. 存入 `userMemory.conversationSummaries`
4. 原对话历史标记为"已过期"或不传给 AI

---

### 3. 课程结构概览

**决策：始终保留完整概览**

```typescript
// 课程结构概览示例
1. 变量 [已完成]
2. 数据类型 [进行中]
3. 运算符 [未解锁]
4. 条件语句 [未解锁]
...
```

**理由**：
- 课程目录页用户可能询问还没学的内容（如"第三章讲什么"）
- 完整概览信息量可控（标题列表几百字）
- AI 信息更充分，可回答更广泛的问题

---

### 4. 消息截断策略

**决策：按"问答对"截断**

**当前问题**：
```
用户: 什么是变量？           → 被截断删除
助理: 变量是...
用户: 那数据类型呢？         → 保留
助理: 数据类型是...          → 只剩这条，AI不知道用户之前问过"变量"
```

**改进方案**：
```typescript
// 1. 先按消息对分组
const messagePairs = [
  { q: "什么是变量？", a: "变量是..." },
  { q: "那数据类型呢？", a: "数据类型是..." }
];

// 2. 从最旧的开始删除整对
while (pairsExceedLimit(messagePairs)) {
  messagePairs.shift();  // 删除最旧的一问一答
}

// 3. 确保问题和回答成对出现
```

---

### 5. 过期对话摘要策略

**决策：AI 自动生成摘要**

**摘要生成时机**：
- 对话结束时检测是否需要生成摘要
- 如果是连续追问（< 10字 且 以问号结尾），不单独生成，合并到原始问题摘要

**追问识别逻辑**：
```typescript
function isFollowUp(message: string): boolean {
  return message.length < 10 && message.trim().endsWith('?');
}
```

**摘要格式**：
```json
{
  "courseId": "python-101",
  "summary": "用户问了Python变量和数据类型的基本概念",
  "timestamp": 1711392000000
}
```

---

### 6. 上下文大小估算

**决策：保持现状（字符数估算）**

- 当前策略：10条消息，2000字符
- 足够覆盖大部分场景
- 引入精确 token 估算增加复杂度，收益不明显

---

### 7. 摘要存储位置

**决策：存入 userMemory**

```typescript
interface UserMemory {
  // ... 其他字段

  // 对话摘要（按课程维度）
  conversationSummaries: Array<{
    courseId: string;
    summary: string;
    timestamp: number;
  }>;
}
```

**理由**：
- userMemory 是全局的，可跨课程参考
- 即使对话历史过期，摘要仍可给 AI 提供参考
- 符合 userMemory 作为"长期记忆"的定位
