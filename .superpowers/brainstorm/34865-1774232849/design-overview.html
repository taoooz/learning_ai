整体设计方案

组件化架构 · Next.js App Router

页面结构
Page 1: 主题输入
输入框 + 开始按钮 → /generate
Page 2: 加载状态
AI 生成中动画 → /course/[id]
Page 3: 课程详情
课程树（纵向线性）+ 开始学习 → /course/[id]/learn
Page 4: 单元学习
学习卡片 → 答题闯关 → 返回课程树

核心组件

CourseTree
纵向线性课程树，展示节点和进度
LearningCard
1-5张自适应学习卡片，支持滑动
QuizQuestion
单选/多选/填空题，即时反馈
ProgressBar
极简进度指示（X/Y）

状态管理

React Context 管理全局状态：
CourseContext 课程数据
ProgressContext 节点进度
localStorage 持久化

AI 集成流程

用户输入主题 → POST /api/generate
→ MiniMax API 生成课程树 JSON
→ 解析存储到 CourseContext
→ 跳转到课程详情页
